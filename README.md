
 Technologies Used

- HTML5
- CSS3

 What I Built

 1. HTML Structure

I created the basic structure of the Budget Tracker using HTML. The page includes:

- A header with the project title and introduction.
- A logo image.
- An Add Expense section.
- A form for entering expense information.
- An expenses section for displaying expenses.

 2. Add Expense Form

The Add Expense section allows the user to enter information about an expense. The form is prepared to collect details such as:

- Expense name
- Amount
- Category

 3. CSS Styling

I used CSS to make the page more organized and readable. I added:

- A page background color.
- Styling for the main heading.
- Spacing and padding.
- A background color for the Add Expense section.
- Centered header content and logo.

 CSS Selectors Used

I used different CSS selectors in the project, including:

- Element selector:'h1`
- ID selector: add-expense`
- Descendant selector:`header img`

These selectors were used to style different parts of the webpage.
